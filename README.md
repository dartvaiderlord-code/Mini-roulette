# Карусель

Трёхмерная настольная аркада для Windows x64 на Unity. За игрушечным столом встречаются от двух до пяти взрослых силачей. Можно играть одному с 1–4 ботами без интернета, создать комнату в локальной сети или подключиться к выделенному серверу.

## Готовый клиент для Windows x64

[Скачать Carousel-Windows-x64.zip](https://github.com/dartvaiderlord-code/Mini-roulette/raw/refs/heads/windows-download/Carousel-Windows-x64.zip). Распакуйте архив целиком и откройте **Carousel.exe**. Для этой сборки нужны 64-разрядная Windows 10/11 и видеодрайвер с OpenGL 3.3. В ZIP уже есть среда выполнения .NET и сервер для соло и LAN.

Этот вариант использует raylib для графики, звука и ввода. Сцена, персонажи, эффекты, меню и сетевой клиент компилируются из тех же C#-файлов в `Assets/Scripts`, что и Unity-версия. Код интеграции с raylib находится в `Desktop`. Для пересборки через .NET 8 SDK выполните из корня репозитория:

```sh
dotnet publish Desktop/Carousel.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -o Builds/Portable
```

## Запуск в Unity

1. Откройте корень проекта через **Unity Hub → Add project from disk** с Unity **2022.3.62f1**.
2. Откройте сцену `Assets/Scenes/Club.unity` и нажмите **Play**.
3. Для отдельного приложения установите модуль **Windows Build Support (Mono)** в Unity Hub, если он требуется вашей установке редактора. Выберите **Carousel → Build Windows x64**. Запустите `Builds/Windows/Carousel.exe`. Для передачи игры другу скопируйте **всю папку Windows**.

Команда сборки для активированного редактора с поддержкой Windows:

```powershell
& "C:\Program Files\Unity\Hub\Editor\2022.3.62f1\Editor\Unity.exe" -batchmode -quit -projectPath "$PWD" -executeMethod Carousel.Editor.BuildDesktop.Windows -logFile build-windows.log
```

В `Assets/StreamingAssets/Host` уже лежат исполняемые файлы **сервера** для Windows и Linux x64. Их использует клиент в режимах «Соло» и «Создать LAN». Игроку не нужны Go или Docker для этих режимов. Графический клиент собирается отдельно в Unity.

## Игра с друзьями

| Режим | Как начать |
|---|---|
| Соло | Выберите «Соло», число ботов и «Начать партию». Игра сразу рассадит участников. |
| Локальная сеть | Один игрок выбирает «По сети → Создать LAN → Открыть комнату». Остальные вводят его адрес в локальной сети и тот же порт. При первом запросе брандмауэра Windows разрешите входящие подключения в частной сети. |
| Выделенный сервер | Запустите `docker compose up -d --build` в корне проекта на хосте с Docker. Все игроки выбирают «По сети → Подключиться» и вводят адрес хоста. Для игры через интернет хост должен принимать входящие подключения на выбранном TCP-порту. |

По умолчанию используется **7777/TCP**. Вариант с Docker запускает один стол на контейнер. Для второго стола запустите ещё один контейнер с другим внешним портом. Статический образ Linux/amd64 собирается из приложенного исполняемого файла и работает от непривилегированного пользователя.

Первый занявший место становится ведущим. Когда собрались 2–5 человек, ведущий нажимает «Начать партию». В выделенной комнате при его выходе роль переходит к следующему подключённому человеку. В режиме «Создать LAN» процесс принадлежит клиенту создателя, поэтому закрытие комнаты завершает сеанс для всех. Ведущий выделенной комнаты может вернуться в лобби для реванша. Новый участник может занять место между партиями.

## За столом

- Камера находится на уровне глаз участника. Поверните мышь к сопернику. Его имя появится под прицелом. **ЛКМ** выполняет ход по выбранной цели. Для выбора своего места удерживайте **F**.
- **R** сразу прокручивает барабан и сохраняет очередь. В сетевой игре все участники видят прокрутку. Для этой возможности на выделенном сервере обновите репозиторий и выполните `docker compose up -d --build`.
- **Esc** освобождает мышь и открывает настройки. Здесь можно переназначить три действия, изменить чувствительность мыши (20–250 %) и вертикальный FOV (50–105°). Параметры сохраняются на этом ПК. В сетевой игре партия продолжается, пока открыто меню.
- Сервер хранит шесть отдельных позиций, текущий индекс и один заряд. Пустой результат при выборе себя сохраняет ход. При выборе соперника ход переходит к следующему живому по кругу.
- Попадание выводит выбранного участника из партии. Если осталось несколько игроков, начинается новый раунд с новым зарядом. Последний участник побеждает.
- Выбывший остаётся подключённым, видит все ходы и может выбрать камеру участника или общий план.
- При попадании разрушаются сегменты головы и детали лица, летят капли и мягкие фрагменты, корпус оседает. Под креслом и на столешнице постепенно расползаются пятна крови. Тело и лужа остаются до конца партии. Все клиенты получают одну цель и одно случайное зерно эффекта. В меню «Эффекты · мягкие» можно отключить тряску и пульсацию для своего экрана.

## Код и проверки

`server/game.go` содержит правила. `Device` связывает оружие, реализацию интерфейса `Magazine` и игровой заряд `Charge`. Другой магазин может реализовать собственные пополнение и активацию. Идентификатор эффекта заряда передаётся клиентам вместе с событием. Новую визуальную реакцию можно подключить в `Stage.ResolveImpact`.

`server/main.go` обслуживает TCP-соединения и передаёт снимки состояния всем местам, включая наблюдателей. Сервер проверяет очередь, цель и ревизию команды. Содержимое барабана остаётся на сервере. В игре используется клиент-серверная топология. Хост в LAN и Docker исполняют одинаковые правила.

`Assets/Scripts/Fighter.cs` строит модели и замкнутые фрагменты головы. `Burst.cs` отвечает за движение обломков, фонтан, отскоки и следы. `Stage.cs` создаёт комнату, предметы, звук и камеры. Модели и разрушаемые детали процедурные. Авторская тема «Midnight Waltz» и пять звуковых эффектов лежат в `Assets/Resources/Audio`. Для выстрела, разрушения и прокрутки использованы переработанные звуки Kenney из Starter Kit FPS (CC0). [Источник звуков](https://github.com/KenneyNL/Starter-Kit-FPS)

Проверка правил с Go 1.22 или новее:

```sh
cd server
go test ./...
```

Проверка пустого запущенного контейнера с Python 3:

```sh
python3 scripts/smoke.py --players 5
python3 scripts/smoke.py --players 2
```

После изменения кода сервера запустите `scripts/build-hosts.sh` из Bash с Go в PATH, затем `docker compose up -d --build`. Скрипт пересобирает оба исполняемых файла для Unity и Docker. Для остановки выделенной комнаты используйте `docker compose down`.
